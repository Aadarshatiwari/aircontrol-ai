# Gesture guide

Start the camera in Simulation. Extend your index finger with the other fingers curled for about a second. Put the fingertip where you want the center of the tracking area.

| Mode | Pose | Result |
|---|---|---|
| Pointer | Index extended | Move cursor |
| Pointer | Index to thumb briefly, then point | Click |
| Pointer | Hold index to thumb, then move | Drag. Open the pinch to drop |
| Pointer | Middle finger to thumb | Right click |
| Pointer | Ring finger to thumb | Double click |
| Pointer | Index and middle extended, then move vertically | Scroll |
| Media | Index to thumb | Play / pause |
| Media | Fingers curled, thumb up or down | Volume up or down |
| Shortcuts | Index to thumb | Run configured shortcut |
| Shortcuts | Middle finger to thumb | Switch to last-used app |
| Presentation | Index to thumb | Next slide |
| Presentation | Middle finger to thumb | Previous slide |
| Keyboard | Point to a key, then pinch index to thumb | Select key |
| Drawing | Hold index to thumb while moving | Draw. Open the pinch to lift the pen |

Hold each command pose briefly and return to pointing between commands. Keep other fingertips away from the thumb when pinching. Open palm and fist can be assigned in Settings alongside the pinch, two-finger and thumb poses. A binding replaces the selected mode’s default for that pose.

After losing tracking, point steadily to resume. Press **Control–Option–Command–Escape** to return to simulation.
